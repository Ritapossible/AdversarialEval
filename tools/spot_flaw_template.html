Why judges get fooled

    
On Telegraph, an evaluator model decides which miner's answer wins. If it rewards length or security vocabulary, the plausible-but-wrong answer wins. Pairwise accuracy on  held-out validation pairs:

    

    
The vertical line is a coin flip (50%). AdversarialEval's range covers two training runs with different random seeds. These validation pairs were written by the same author as the training data, so they overstate real-world accuracy. The headline number will come from a test set written by independent security reviewers.
