Evidence and limits

Everything here can be checked.

Rules and answer keys are committed before any paid call, payments are matched to the chain or the node's ledger, and every result file is fingerprinted and signed. This page lists the evidence and what it does not show.

What we don't claim

  • Everything runs on testnet: test USDC, testnet miners, routing that changes daily.
  • Samples are small (16 to 46 cases per test); read differences of one or two as noise.
  • A strong AI model with web search matched our checked results on known advisories. Our claim is that paid answers should never be trusted unchecked, not that they beat a free lookup.
  • The adapter scored 77.5% on the independent test, below the 80% bar we set ourselves.
  • The Mind's rule against acting on text inside miner answers is an instruction to a model, not a sandbox.
  • Payout addresses are an upper bound on how many independent providers exist: one team can use several.
  • Every result file is fingerprinted and signed; node tools/evidence_manifest.mjs verify fails if one changes.

Check it yourself

Every report and run file is hashed (SHA-256) and the list is signed with Ed25519. The public key is in the repository; the private key never is. The check runs on every push.

The signed list of all 333 files is also anchored on Solana devnet: its SHA-256 is in a memo transaction (2J9e6x…, 28 Nov 2026; earlier anchors in evidence/ANCHORS.json), so anyone can check the evidence existed unchanged by then with node tools/anchor_evidence.mjs verify.

git clone https://github.com/Ritapossible/AdversarialEval
cd AdversarialEval
node tools/evidence_manifest.mjs verify
python bench/solana_reconcile.py bench/out/solana-v2
