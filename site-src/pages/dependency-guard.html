Dependency.Guard checks before it trusts.

For teams whose coding agents add and upgrade packages, and must not ship a known-vulnerable or malicious version. It runs inside Minds by Animoca Brands, buys its intelligence from Telegraph, and never acts on a paid answer it hasn't checked.

Open the Mind ↗ See the evidence

How it works

  1. [1]Buy one answerOne SECURITY_REVIEW answer per package from Telegraph's ranked route, through Anjoman. Never three providers by default.
  2. [2]Check it for freeVerified Ask compares the verdict with OSV for that exact version, confirms every cited advisory exists and applies, and that the version was ever published.
  3. [3]DecidePASS, BLOCK or FLAG, with the advisories, every receipt and the cost. One other provider is asked only when the check proves the answer wrong. Every PASS and BLOCK is re-checked for free each day, and a PASS that stops verifying raises an alert.
