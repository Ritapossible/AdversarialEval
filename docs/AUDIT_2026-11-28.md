# Audit, 28 Nov 2026: findings and their status

A full audit of the repository, the live site and its API, GitHub Actions, the payment paths and the
scoring code, done as an outside reviewer would, followed by fixes. Each fix was verified and
followed by the full local CI (`scripts/ci_local.sh`). Signed reports were never edited: corrections
are in new files. Status key: **Fixed**, **Owner** (needs an action only the owner can take), or
**Accepted** (kept on purpose, with the reason).

## Security

| # | Finding | Severity | Status and verification |
|---|---|---|---|
| S1 | The owner's private email was in the `From:` headers of `docs/upstream/*.patch` and in the author field of every commit | High | **Fixed** in files (`bf54e7d`): the noreply address, and the repository's git email now uses it, so new commits don't expose it. **Owner:** removing it from the existing 448 commits needs a history rewrite and a force push of `main` |
| S2 | The Mind held the Anjoman key (typed into its chat) and read raw miner text, protected only by a prompt rule | High | **Fixed in code** (`3ffb74d`): `POST /api/guard` holds the key server-side and returns only validated fields, with no miner free text. It is live and refuses to answer until configured (503); 7 offline tests. **Owner:** set `ANJOMAN_API_KEY` and `GUARD_TOKEN` in Vercel, point the Mind at `/api/guard`, then revoke the old key (`mind/README.md` §7) |
| S3 | Model-written and third-party code ran as root with network access; reports called it a "sandbox" | Medium | **Fixed** (`f887969`): no network, the `nobody` user and resource limits for model-written code; `nobody` and limits for the app under a pre-deployment check. An escape test passes. Re-runs under isolation reproduce all 24 reference outcomes and all 6 Qwen-Agent candidates. Errata: `eval/reports/2026-11-28-isolation-errata.md` |
| S4 | The API's rate limits are per serverless instance | Low | **Accepted.** Both endpoints need a secret token. The Guard also has a daily spend cap, and the Anjoman balance is the hard cap. A shared limiter needs an external store (Upstash or Vercel KV); revisit if the token is ever shared |
| S5 | Secrets left in the environment: the Hugging Face write token and the Anjoman key | Low | **Owner:** delete the HF token (huggingface.co → Settings → Access Tokens) and remove it from the environment's network secrets; rotate the Anjoman key after judging |
| S6 | Pre-registration timing rested on git timestamps, which the author can set | Low | **Fixed** (`c96d7ac`): `docs/SUBMISSION_EVIDENCE.md` pairs each freeze commit with the first server-timestamped payment (Solana block time) and links the repository's activity log |

## Found while fixing

- **An edit to a signed report broke the evidence check.** It was restored byte for byte and the
  change moved to an addendum.
- **One commit (`f887969`) was pushed while a CI check failed.** The commit command piped CI through
  `tail`, which hid its exit code. Fixed in `e856d64`, and commits are now gated on CI's own exit
  code.
- **The Qwen-Agent checker left 4 GB per run and filled the disk.** It now removes its work folder
  (`--keep-work` keeps it).
- **The isolation first broke the app** (an unreadable CA bundle, then a root-owned temp folder).
  Both were fixed, and the outcomes then matched exactly.
- **Evidence re-signed** (338 files) and anchored again on Solana devnet (`evidence/ANCHORS.json`);
  `anchor_evidence.mjs verify` matches.
