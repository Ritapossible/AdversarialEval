# Recruiting independent reviewers (U1)

We need 2–3 people with security-review experience, each writing about 20 test pairs
(2–3 hours). Their pairs become the frozen test set behind our headline number.
Credit: named in the dataset card and the write-up (or anonymous if they prefer).

## Paste-ready message

> Hi! I'm building **AdversarialEval**, an open evaluator for the Telegraph protocol's
> SECURITY_REVIEW Intent. It's my entry in the Telegraph Hackathon Season II (Evaluators
> track), which has cash prizes. Reviewers get credit, not payment. It ranks security-review answers by whether they survive scrutiny
> (fake CVE ids, wrong version ranges, false alarms, missed criticals), not by how fluent
> they sound.
>
> I'm looking for 2–3 people with AppSec / pentest / code-review experience to write about
> 20 short test questions, each with a better and a worse answer. It takes about 2–3 hours.
> Your pairs become the independent test set that decides whether our model is any good,
> so the point is that you write *differently* from us.
>
> Guide (5-minute read): https://github.com/Ritapossible/AdversarialEval/blob/main/docs/REVIEWER_GUIDE.md
> Template: https://github.com/Ritapossible/AdversarialEval/blob/main/templates/test_pairs_template.csv
>
> You'll be credited in the open dataset and write-up. Interested? Reply here or DM me.
