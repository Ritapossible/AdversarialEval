Dependency.Guard checks before it trusts.

For teams whose coding agents add and upgrade packages, and must not ship a known-vulnerable or malicious version. It runs inside Minds by Animoca Brands, buys its intelligence from Telegraph, and never acts on a paid answer it hasn't checked.

Open the Mind ↗ See the evidence

How it works

  1. [1]Buy one answerOne SECURITY_REVIEW answer per package from Telegraph's ranked route, through Anjoman. Never three providers by default.
  2. [2]Check it for freeVerified Ask compares the verdict with OSV for that exact version, confirms every cited advisory exists and applies, and that the version was ever published.
  3. [3]DecidePASS, BLOCK or FLAG, with the advisories, every receipt and the cost. One other provider is asked only when the check proves the answer wrong. Every PASS and BLOCK is re-checked for free each day, and a PASS that stops verifying raises an alert.

Results so far

with and without Telegraph, testnet
Trusting the answer
On 26 packages: 3 vulnerable versions passed, and 2 packages that don't exist were called "Secure".
With the check
Nothing unsafe was approved: 24 decided correctly, 2 sent to a person.
Code review
23 subtle functions: Telegraph's route 13, its best miner 11; the Mind 23, overruling all 10 wrong answers.
Paid on Solana
21 hard Solana cases, every call paid in USDC on Solana devnet and confirmed on-chain: Telegraph's ranked answer trusted, 6 right, approving malware 5 times; with the check, 20 right, nothing unsafe approved, $0.35.
Solana stack
16 versions, including the hijacked @solana/web3.js 1.95.7: every bad version blocked; trusting the answer gave confident verdicts on 2 versions that don't exist; with the check, 16 of 16 for $0.22.
Honest result
The Mind on its own matched these scores by querying OSV directly. For known package vulnerabilities a free lookup is the bar; the value is that wrong paid answers never became decisions.
