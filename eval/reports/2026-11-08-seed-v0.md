## Reading

- **Overall, the training set has no exploitable shortcut.** Every naive scorer lands between 47% and 58%, and the kit dataset gate passes (length shortcut 51.7%, question-blind bag-of-words probe 57.5%).
- **Per-family tells remain**, and a model could learn them inside a family:
  - In F6 (false alarm), *shorter-wins* is 100%: the false-alarm answer is always the longer one.
  - In F3 (missed critical), *more-security-terms* is 100% and *more-ids-cited* 92%: the complete answer naturally names more issues.
  - In F1/F2/F7/F10, *longer-wins* is 75–100%.
  Next batches invert these patterns per family. Examples: F6 rows with a short false alarm and a longer, careful Secure answer; F3 rows where the incomplete answer cites more (irrelevant) ids.
- **The validation set is too small to read (n=14)**, and *tfidf-to-prompt* is 79% there. Its terse chosen answers repeat the prompt's identifiers. Grow it to about 80 and add rejected answers that echo the prompt.
- The kit's "repeated rejected answer" check fails on the validation set only because it has 14 rows (1/14 > 2%). It isn't a real duplicate, and the training set passes the check.
