## Reading: did the minimal pairs break the polarity shortcut?

Same yardstick for both models: the 87-pair validation set (39 hand-written second voice +
48 held-out generated minimal pairs from 13 packages training never saw). Seed 7 for both.

| | cpu-v1-seed7 (95 hand-written pairs) | **cpu-v2 (252: + 146 generated + 11 targeted)** |
|---|---|---|
| Overall | 66.7% (CI 56.2–75.7) | **74.7%** (CI 64.7–82.7) |
| Generated minimal pairs | 50% | **73%** |
| F2-out (right answer: patched), no range | 0% (0/7) | **64%** (7/11) |
| F2-out with the range in the prompt | 0% (0/4) | **100%** (4/4) |
| F2-in (right answer: affected), no range | 100% | 57% |
| F2-in with the range in the prompt | 100% | 80% |
| Hand-written | **87%** | 77% |

- **The shortcut is broken.** The 95-pair model always preferred the "vulnerable" answer
  (100% / 0%). cpu-v2 is balanced across F2-in and F2-out.
- ~~The evidence in the prompt is what makes version reasoning learnable~~ **Retracted
  2026-11-11: this didn't replicate.** Seed 7 got 8/9 with the range quoted; seed 13 on the
  identical data got 4/9, and F2 overall was 52%. See the "Second seed" section below.
- **The cost:** hand-written accuracy fell 10 points, mostly F5/F6 (80% → 60%). Candidates:
  dilution (146 of 252 training pairs are templated), the early stop at epoch 3 (validation
  loss rose after it), or seed noise (about ±10 points, see the seed study). The next step
  runs a second seed and mines the hand-written errors.
- **Caveat:** validation loss on these same 87 pairs picked the epoch, so 74.7% is mildly
  optimistic. The independent test split (U1) is still empty.

## Second seed (added 2026-11-11): what replicates and what doesn't

Same 252-pair snapshot and config, seed 13 (`eval/reports/2026-11-11-cpu-v2-seed13.md`):

| val 87 | seed 7 | seed 13 |
|---|---|---|
| Overall | 74.7% | 69.0% (CI 58.6–77.7) |
| Hand-written | 77% | 77% |
| Generated minimal pairs | 73% | 62% |
| F2-out (right answer: patched); the 95-pair model got 0% | 64% | 64% |
| F2 overall | 73% | 52% |
| F2 with the range in the prompt | 8/9 | 4/9 |

- **Replicates:** the polarity shortcut is broken (F2-out 0% → 64% in both seeds), and
  hand-written accuracy is stable at 77%.
- **Doesn't replicate:** version reasoning. Seed 13 is at chance on F2 even with the range
  quoted. At this data size ModernBERT-base doesn't reliably learn to compare version strings.
  Per U7, the write-up must not claim version-range robustness. F2 stays mainly as pool
  material and as a shortcut breaker. Testing whether more F2 pairs fix it needs a much
  larger generated set (a GPU job).
- **Mean of two seeds: about 72%.** The lower CI bounds (59–65%) are below the 70% floor. Not
  ready to register.
